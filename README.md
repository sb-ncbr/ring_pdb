## How to run

### Web app

Dev

```bash
npm run dev
```

Prod

```bash
npx vite build --mode production
npm run preview
```

### API

Install deps

```bash
python -m venv venv
. venv/bin/activate
pip install -r requirements.txt
```

Run server

```bash
python app.py
```
